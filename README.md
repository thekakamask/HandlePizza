# 🍕 **HandlePizza**
**HandlePizza** est le projet d’application de la société **OC Pizza**.  
Il vise à structurer un système d’information sur mesure pour un réseau de pizzerias en croissance, orienté commande, production, livraison/retrait, paiement et gestion des stocks.

L’objectif de ce repository est de produire une documentation projet complète et professionnelle (MOA, MOE, équipes techniques), en réutilisant les travaux d’analyse des besoins et de conception technique réalisés précédemment.

## 📋 **PROJECT SCOPE**
- 📌 **Contexte métier**
  - OC Pizza est une chaîne en expansion (5 points de vente existants, nouvelles ouvertures prévues).
  - Le besoin principal est un SI centralisé, temps réel, déployable sur l’ensemble du réseau.

- 🧩 **Fonctionnalités cibles documentées**
  - Commande multi-canal (web, téléphone, sur place)
  - Paiement en ligne et différé
  - Suivi de commande en temps réel
  - Gestion des stocks d’ingrédients
  - Aide-mémoire recettes pour la production
  - Notifications client
  - Pilotage opérationnel magasin / réseau

- 🛠 **Hors périmètre de ce projet**
  - Développement de l’application
  - Déploiement logiciel en production
  - Exploitation run complète (hors dossier d’exploitation documentaire)
